# ADR-0002 — Отложенная инициализация RealtimeGateway

**Статус:** Принято  
**Дата:** 2026-08-12

## Контекст

`realtimeGateway` экспортируется как singleton и импортируется repository-слоем.
Его конструктор подписывался на `PB_CONNECT` во время загрузки модуля. Это
создавало сетевой SSE side effect до явной потребности в realtime и ломало
изолированные unit-тесты в окружении без `EventSource`.

## Решение

Создание singleton остаётся безопасным и ленивым. Connection listeners
инициализируются один раз при первой явной подписке на коллекцию через публичный
метод `subscribe`. Повторные подписки не регистрируют обработчики повторно.

## Альтернативы

- Глобально добавлять `EventSource` mock в каждый test setup — скрывает ошибку
  жизненного цикла и оставляет импортный сетевой side effect.
- Удалить автоматический reconnect — уменьшает функциональность и меняет
  runtime-контракт.

## Последствия

Импорт repository и связанных модулей больше не открывает realtime-соединение.
Первый пользовательский realtime-сеанс сохраняет прежнюю регистрацию
`PB_CONNECT`, offline/online handlers и reconnect behavior. Контракт покрыт
тестом на отсутствие импортного side effect и на инициализацию первой подписки.
