# Детальное руководство по развертыванию инфраструктуры Knock-Knock

## 1. Изолированная Сетевая Архитектура (FRP Туннель + VPS)

Инфраструктура проекта разделена на две полностью независимые зоны: **VPS Ninja** (внешняя точка входа) и **Домашний Сервер** (хранение данных и выполнение кода).

```
[Пользователь / Браузер]
         │
         ▼ (HTTPS 443)
┌─────────────────────────────────────────────────────────────┐
│ 🌐 VPS "Ninja" (infra/vps_new/)                             │
│                                                             │
│   • whoami-nginx   (Let's Encrypt SSL)                     │
│   • whoami-frps    (Сервер туннеля, infra/vps_new/frps.toml)│
│   • whoami-push    (Push Gateway)                           │
│   • whoami-livekit (WebRTC)                                 │
└──────────────────────────────┬──────────────────────────────┘
                               │
            🔒 Шифрованный TLS-туннель FRP (Порт 7443)
                               │
┌──────────────────────────────▼──────────────────────────────┐
│ 🏠 Домашний Сервер (infra/tunnel/, infra/prod/, infra/dev/) │
│                                                             │
│ 1. Системный туннель (24/7):                                │
│   • whoami-frpc (infra/tunnel/frpc.toml)                    │
│                                                             │
│ 2. Приложения (Управляются через make stop-all/start-all):   │
│   • whoami-pb   (PocketBase Prod, порт 8090)                 │
│   • whoami-web  (React Web App, порт 3000)                  │
│   • whoami-pb-dev (PocketBase Dev, порт 9090)               │
│   • ssh_home    (SSH Доступ, порт 6000)                     │
└─────────────────────────────────────────────────────────────┘
```

---

## 2. Разделение Конфигураций Туннеля FRP

### 🌐 Серверная часть (VPS Ninja)
* **Конфиг**: `infra/vps_new/frps.toml`
* **Назначение**: Принимает входящие соединения с домашнего сервера на порту `7443` и проверяет токен авторизации `FRP_TOKEN`.

### 🏠 Клиентская часть (Домашний Сервер)
* **Конфиг**: `infra/tunnel/frpc.toml`
* **Compose**: `infra/tunnel/docker-compose.yml`
* **Назначение**:
  - Запускается один раз как фоновый системный сервис (`make start-tunnel`).
  - Держит связь 24/7 с VPS `149.33.42.8:7443`.
  - **НЕ ЗАТРАГИВАЕТСЯ** при остановке приложений через `make stop-all`.
  - Пробрасывает 4 внутренних маршрута:
    1. `whoami_web` (3000 -> 3000)
    2. `whoami_pb` (8090 -> 8090)
    3. `whoami_pb_dev` (127.0.0.1:9090 -> 9090)
    4. `ssh_home` (127.0.0.1:22 -> 6000)

## 3. Команды управления (Makefile)

 На домашнем сервере используется единый пульт `Makefile`:

```bash
# Системное управление туннелем (Запускается 1 раз)
make start-tunnel  # Запустить постоянный клиент туннеля 24/7
make stop-tunnel   # Остановить клиент туннеля
make restart-tunnel # Перезапустить туннель

# Управление приложениями (БД + Веб)
make start-all     # Запустить Prod, Dev и Mailpit (туннель НЕ затрагивается)
make stop-all      # Остановить приложения (туннель продолжает работать!)
make start-prod    # Запустить только Prod среду
make start-dev     # Запустить только Dev среду
```

## 4. Обслуживание и бэкапы

### Бэкап базы данных
PocketBase хранит данные в SQLite базе `pb_data/data.db`. База находится исключительно на физическом домашнем сервере, что гарантирует полную приватность. Копирование выполняется сохранением директории `pb_data`.
