# План подготовки к пробному релизу в Production (Nemo)

На основе анализа архитектуры и нерешенного технического долга сформирован подробный план по доработке оставшихся задач перед выкаткой в продакшн.

## Этап 1: PWA & Offline UI (Пользовательский опыт)
Цель: Сделать приложение похожим на нативное и прозрачно сообщать пользователю о состоянии сети.

- `[x]` **1.1. Кастомный UI установки (A2HS)**
  - Реализовать хук `useInstallPrompt` для перехвата события `beforeinstallprompt`.
  - Создать компонент `InstallPromptModal` (или `InstallPromptBanner`) в соответствии с дизайн-системой (никакого хардкода стилей, использование токенов `var(--...)`).
  - Интегрировать показ компонента при открытии приложения.
- `[x]` **1.2. Offline-индикация (Network Status)**
  - Создать хук `useNetworkStatus` (слушает события `online` и `offline`).
  - Разработать глобальный компонент `NetworkStatusBanner`, который будет ненавязчиво показываться поверх UI с анимацией: "Соединение разорвано" (ошибка) и "Соединение восстановлено" (зеленый).

## Этап 2: Отложенная отправка сообщений (Background Sync & Outbox)
Цель: Обеспечить бесшовную отправку сообщений при пропадании интернета. 

- `[x]` **2.1. Локальная очередь (Outbox в Dexie.js)**
  - Расширить локальную БД таблицей `outbox` для хранения черновиков исходящих сообщений.
- `[x]` **2.2. Background Sync в Service Worker**
  - Зарегистрировать периодическую/background синхронизацию в `sw.ts`.
  - Написать фоллбэк: если Background Sync не поддерживается, хук `useNetworkStatus` при событии `online` сам триггерит вычитывание очереди из Dexie.
- `[x]` **2.3. Интеграция Outbox с UI**
  - В `MessageList` отображать сообщения из локального Outbox со статусом "часики" (Pending).

## Этап 3: Рефакторинг Realtime Event Bus & SSE Reconnection
Цель: Погасить технический долг, снизить риск утечек памяти и потери сообщений при обрывах связи.

- `[x]` **3.1. Централизованный Realtime Gateway**
  - Создать единый синглтон-шлюз `RealtimeGateway`, который инкапсулирует работу с `pb.realtime`.
  - Шлюз будет транслировать события через локальный `EventEmitter`.
- `[x]` **3.2. Авто-реконнект (SSE Handling)**
  - Обработка обрывов соединения в `RealtimeGateway` (Exponential Backoff).
  - При успешном переподключении — запуск синхронизации пропущенных событий.
