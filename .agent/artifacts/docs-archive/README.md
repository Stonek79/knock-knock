# Архив документации

Здесь находятся исторические документы проекта. Они сохранены для контекста и
восстановления решений, но не являются актуальными инструкциями.

Актуальная документация находится в `docs/`, прежде всего:

- `docs/CURRENT_STATE.md` — фактическая инфраструктура и согласованные правила;
- `docs/ARCHITECTURE.md` — общие инженерные принципы;
- `docs/SECURITY_CONFIG.md` — базовые требования безопасности;
- `.agent/artifacts/prod_readiness_plan.md` — критерии готовности Prod;
- `.agent/artifacts/TAURY_PLAN.md` — план Tauri/Desktop.
