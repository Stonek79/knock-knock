# 📞 План реализации WebRTC (Аудио/Видео звонки) для Knock-Knock на домене whoami.ninja

## 1. Архитектурное видение (Zero-Knowledge & Mobile-First Design)

Архитектура звонков строится по принципу **Zero-Knowledge (ZK)**:
- Серверная инфраструктура **не знает** реальных имен участников и их сетевых IP-адресов.
- Медиа-трафик шифруется по стандарту **DTLS-SRTP** и легко обходит блокировки DPI.
- UI звонилки на 100% строится на **собственном UI-ките проекта** (`src/components/ui/`), полностью отказавшись от дефолтных UI элементов LiveKit.

### Инфраструктурный стек (`whoami.ninja`):
- **LiveKit Server (`whoami-livekit`)**: Публичный SFU-сервер на VPS (`149.33.42.8`), маршрутизирует UDP-пакеты (порты `50000-60000`). Обернут Nginx-проксированием WSS по адресу `wss://whoami.ninja/livekit/`.
- **Push & LiveKit Token Gateway (`whoami-push`)**: Внутренний сервис на VPS (`http://whoami-push:4000`), генерирующий подписанные JWT-токены LiveKit по защищенному внутреннему каналу. Проксируется через Nginx на `/push/`.
- **PocketBase Backend (`whoami-pb`)**: Выступает в роли авторизтора. Выполняет проверка прав доступа к комнате, создает анонимизированный identity (`anon_${md5}`), логирует звонки в `call_logs` с зашифрованными метаданными `encrypted_metadata` и планирует Blind Push.
- **Nginx VPS (`infra/vps_new/nginx/default.conf`)**: Обрабатывает SSL/TLS, поддерживает WebSockets (`Upgrade` / `Connection`) и маршрутизирует запросы на `whoami-frps`, `whoami-push` и `whoami-livekit`.

## 2. Архитектура UI/UX и Дизайн-Системы

### 🎨 Использование единой дизайн-системы (`src/components/ui/`)
Вместо монолитных сторонних компонентов (`<VideoConference />`) используются исключительно компоненты нашего кастомного UI-кита:
- `Button` и `IconButton` для всех панелей управления.
- `Avatar` для открытых профилей и `Card`/`Badge` для статуса соединения.
- `Dialog` / `Modal` для окон входящих вызовов.
- `Tooltip` для подсказок к кнопкам управления.

### 🎭 Поддержка Открытых и Приватных/Инкогнито контактов
1. **Открытый контакт (Бизнес / Публичный)**:
   * Отображение публичного имени и реального аватара (`Avatar`) из списка контактов.
2. **Приватный собеседник (Инкогнито / ZK / Фантомный профиль)**:
   * Отображение стилизованной анонимной карточки с неоновой аватаркой-маской 🕵️‍♂️.
   * Текст подписи: **«Приватный собеседник»** + плашка **«Зашифрованный E2EE-звонок»** (`Badge`).
   * Полное исключение утечки персональных данных или системных UUID в DOM приложения.

### 📱 Режим Picture-in-Picture (PIP / Компактный плавающий виджет)
* При клике на кнопку «Свернуть» окно звонка сжимается в компактный плавающий виджет `CallPIPWidget.tsx` в углу экрана (`isMinimized: true` в Zustand-сторе `useCallStore`).
* Пользователь может параллельно читать чаты, отправлять медиафайлы и переходить по разделам приложения, не прерывая аудио/видео вызов.

### 🎨 Динамическая темизация (Telegram-Style Themes)
* UI звонков опирается исключительно на глобальные CSS-переменные из `index.css` (`var(--color-bg-primary)`, `var(--color-surface-blur)`, `var(--color-text-primary)`).
* Поддержка всех встроенных тем (`default`, `neon`, `emerald`), а также будущих пользовательских тем оформления.
