## Этап 2: Подготовка коллекции `invites` в PocketBase
- [ ] Создать схему `invites` (`room_id`, `token` (уникальный индекс), `expires_at`, `created_by`, `max_uses`, `uses_count`).
- [ ] Настроить API-правила:
  - `listRule`, `viewRule`: могут просматривать все (чтобы по токену получить инфу о комнате).
  - `createRule`: только если пользователь имеет право приглашать в комнату (модератор, или участник публичной группы с правами).
  - `deleteRule`: только создатель инвайта или модератор комнаты.
- [ ] Написать `pb_hooks` или `cron` задачу для автоматической очистки протухших инвайтов.

## Этап 3: Доработка UI создания группы (CreateGroupDialog)
- [ ] Интеграция типа аккаунта: использовать `useAuthStore` для получения `profile_type`.
- [ ] **Если Открытый (Public)**:
  - Разрешить поиск пользователей.
  - Добавить чекбокс "Только модератор может приглашать" (переключает комнату в режим `private`/`public`).
  - По завершению создания показывать QR-код / Инвайт-ссылку (безлимитную для модератора).
- [ ] **Если Закрытый (Private)**:
  - Скрыть поиск пользователей.
  - Оставить только ввод названия и выбор параметров инвайт-ссылки:
    - Время жизни: 15 минут, 1 час, 24 часа.
    - Количество использований: 1 или более.
  - По завершению создания генерировать ссылку/QR и выдавать пользователю.

## Этап 4: Разработка логики генерации инвайтов в клиенте
- [ ] Написать сервис генерации инвайтов:
  1. Вызов PocketBase для создания `invites` (получаем `token`).
  2. Взятие локального `ROOM_MASTER_KEY` из стейта.
  3. Склейка в формат `https://nemo.app/join/TOKEN#ROOM_MASTER_KEY`.
- [ ] Компонент `InviteLinkViewer` для отображения ссылки и генерации QR-кода.

## Этап 5: Разработка страницы `/join/:token`
- [ ] Добавить роут `/join/:token`.
- [ ] При заходе:
  1. Парсинг `TOKEN` из URL и `ROOM_MASTER_KEY` из хэша (`location.hash`).
  2. Запрос к PocketBase на проверку `invites` по `TOKEN`.
  3. Если инвайт валиден, отобразить информацию (Имя группы, аватар) и кнопку "Присоединиться".
- [ ] Обработка вступления:
  1. Вызов API вступления. Сервер через `pb_hooks` (или клиент напрямую) добавляет `user` в `room_members` и инкрементирует `uses_count` в `invites`.
  2. Клиент шифрует `ROOM_MASTER_KEY` своим публичным ключом и кладет в `room_keys`.
  3. Редирект в чат.
