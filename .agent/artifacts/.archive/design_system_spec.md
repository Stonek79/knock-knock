# Knock-Knock Design System Specification

Этот документ представляет собой техническую спецификацию (Design System Specification) для интерфейса мессенджера Knock-Knock, основанную на принципах Mobile-First, премиальном дизайне и строгой CSS-архитектуре.

---

## 1. Цветовые палитры (OKLCH)
Все цвета управляются через CSS-переменные в пространстве `oklch`. Для полупрозрачности и состояний `hover`/`active` используется функция `color-mix(in oklch, ...)` вместо хардкодных значений с прозрачностью.

### 1.1. Default (Утилитарная тема)
**Стиль:** Чисто, знакомо, утилитарно. 
Это базовая тема, которая обеспечивает максимальную читабельность по умолчанию.

| Элемент | Light Mode (`oklch`) | Примерный HEX | Dark Mode (`oklch`) | Примерный HEX |
| --- | --- | --- | --- | --- |
| **Background** | `oklch(96% 0.01 260)` | `#f0f2f5` | `oklch(20% 0.02 260)` | `#111b21` |
| **Surface** | `oklch(100% 0 0)` | `#ffffff` | `oklch(25% 0.02 260)` | `#202c33` |
| **Primary (Акцент)** | `oklch(65% 0.15 160)` | `#00a884` | `oklch(65% 0.15 160)` | `#00a884` |
| **Outgoing Bubble** | `oklch(95% 0.06 140)` | `#d9fdd3` | `oklch(40% 0.1 160)` | `#005c4b` |

### 1.2. Emerald Luxury (Эталон Desktop)
**Стиль:** VIP, Природа, Золото, Платина, Glassmorphism.

* **Background (Глубокий лесной):** `oklch(25% 0.05 150)`
* **Surface (Glass):** `color-mix(in oklch, oklch(30% 0.05 150) 60%, transparent)`
* **Primary (Изумруд):** `oklch(60% 0.18 150)`
* **Accent (Золото):** `oklch(75% 0.15 80)`
* **Borders (Золото/Серебро Glass):** `color-mix(in oklch, var(--accent) 30%, transparent)`
* **Специфика:** Четкие тонкие границы (`1px`), слабое размытие (`backdrop-filter: blur(8px)`).

### 1.3. Cosmic Neon (Эталон Mobile Nav)
**Стиль:** Киберпанк, Голография, Floating Glass (смягченные, не кислотные тона).

* **Background (Индиго):** `oklch(20% 0.08 300)`
* **Surface (Floating Glass):** `color-mix(in oklch, oklch(25% 0.1 300) 40%, transparent)`
* **Primary (Неоновый голубой):** `oklch(70% 0.2 250)`
* **Accent (Неоновый розовый):** `oklch(65% 0.25 340)`
* **Специфика:** Сильное размытие (`backdrop-filter: blur(20px)`), матовый эффект.

## 2. Типографика и Отступы (`rem` scale)

Вся дизайн-система опирается на корневой размер шрифта (`--base-font-size`). При его изменении все компоненты, отступы и радиусы масштабируются пропорционально.

```css
/* Базовый масштаб (Zustand Theme Store будет изменять --base-font-size) */
html {
  --base-font-size: 16px;
  font-size: var(--base-font-size);
}
```

### Шкала отступов (Spacing)
* `--space-xs`: `0.25rem` (4px)
* `--space-sm`: `0.5rem` (8px)
* `--space-md`: `1rem` (16px) - *Базовый отступ интерфейса*
* `--space-lg`: `1.5rem` (24px)
* `--space-xl`: `2rem` (32px)
* `--space-2xl`: `3rem` (48px)

### Типографическая шкала (Typography)
* `--text-xs`: `0.75rem` (12px) — Временные метки, статусы, мелкие лейблы.
* `--text-sm`: `0.875rem` (14px) — Вспомогательный текст.
* `--text-base`: `1rem` (16px) — Основной текст сообщений.
* `--text-lg`: `1.125rem` (18px) — Подзаголовки.
* `--text-xl`: `1.5rem` (24px) — Заголовки (H2).
* `--text-2xl`: `2rem` (32px) — Крупные заголовки (H1).

### Скругления (Border Radius)
* `--radius-sm`: `0.25rem`
* `--radius-md`: `0.5rem`
* `--radius-lg`: `1rem`
* `--radius-full`: `9999px`

## 3. Структура Компонентов

### 3.1. Карточки Чата (Message Bubbles) на базе Cosmic Neon
* **Фон (Glass):** `color-mix(in oklch, var(--surface) 60%, transparent)`
* **Размытие:** `backdrop-filter: blur(20px)`
* **Обводка:** `1px solid color-mix(in oklch, var(--primary) 20%, transparent)`
* **Геометрия:** Базовый `--radius-lg` с асимметричным скруглением для "хвостика" (например, `border-bottom-right-radius: 0` для исходящих сообщений).
* **Внутренние отступы:** `padding: var(--space-sm) var(--space-md)`
* **Тень:** Мягкая падающая тень для отделения от фона `box-shadow: 0 4px 16px color-mix(in oklch, #000 10%, transparent)`.

### 3.2. Плавающее меню (Bottom Nav Bar - Mobile)
> В мобильной версии навигация не прилипает жестко к нижнему краю экрана, а висит в воздухе в виде "пилюли" (Floating Pill).

* **Позиция:** Отступ от нижнего края экрана `var(--space-lg)`. Позиционирование `fixed` или `absolute` с выравниванием по центру.
* **Форма:** `--radius-full`
* **Фон:** Матовое стекло Индиго (`color-mix(in oklch, var(--surface) 40%, transparent)` + `blur(20px) saturate(150%)`).
* **Контур:** Светящаяся обводка `1px solid color-mix(in oklch, var(--accent) 30%, transparent)`.
* **Тень:** Неоновое свечение `0 8px 32px color-mix(in oklch, var(--primary) 20%, transparent)`.

## 4. Архитектура Макетов: Desktop 3 Columns (Emerald Luxury)

Десктопная версия базируется на строгом 3-колоночном макете, обернутом в `<Flex className={styles.layout}>` с высотой `100vh` и `overflow: hidden`. Разделители колонок — это не просто линии, а стеклянные границы (borders), просвечивающие базовый фон.

1. **Column 1: Навигация / Папки (Sidebar Layout)**
   * **Ширина:** `min(25%, 300px)`
   * **Стиль:** Глубокий лесной фон `var(--bg)`. Тонкая линия серебра/золота справа: `border-right: 1px solid var(--border-glass)`.
2. **Column 2: Список Чатов (Chat List)**
   * **Ширина:** `min(30%, 400px)`
   * **Стиль:** Слегка осветленное стекло. Скрытый системный скроллбар, кастомный тонкий скроллбар с акцентным цветом при наведении.
3. **Column 3: Рабочая область (Main Chat Area)**
   * **Ширина:** `flex: 1`
   * **Структура:**
     * *Header (Top):* Стеклянная панель с эффектом Blur, накладывающаяся поверх сообщений.
     * *Message List (Center):* Зона скролла.
     * *Input Area (Bottom):* Плавающая или закрепленная стеклянная панель ввода.

## 5. Микро-взаимодействия

### 5.1. Динамичный Input (Микрофон ↔ Отправить)
* **Начальное состояние:** В инпуте пусто (`value === ""`). Отображается иконка микрофона. Кнопка имеет нейтральный/акцентный цвет.
* **Транзиция:** При вводе первого символа:
  1. Иконка микрофона уменьшается (`transform: scale(0.8)`) и уходит в `opacity: 0` (за 150-200ms).
  2. Иконка "Отправить" (Send/Arrow) появляется (`opacity: 1`, `transform: scale(1) translateY(0)`) из состояния сдвига вниз (`translateY(10px)`).
* **Стиль кнопки Отправить:** Активируется яркий акцентный цвет (Neon Blue / Emerald Green) с появлением легкого свечения (`box-shadow`), сигнализируя о готовности.

### 5.2. Статусы сообщений (Галочки)
Вместо текстовых лейблов ("Delivered", "Read") используются минималистичные иконки (из открытых библиотек типа Lucide / Radix Icons).

* **Отправлено / Доставлено (`✓`):** 
  * Иконка: `Check`
  * Цвет: Нейтральный полупрозрачный, `color-mix(in oklch, var(--text-base) 50%, transparent)`.
* **Прочитано (`✓✓`):**
  * Иконка: `CheckCheck` (или две `Check`, расположенные рядом с перекрытием).
  * Цвет: Яркий акцент (Primary).
  * **Анимация:** При переходе из статуса "Доставлено" в "Прочитано" вторая галочка появляется с микро-анимацией: `transform: scale(0.5) -> scale(1)` + вспышка (краткое увеличение яркости).
